FAQ

Pertanyaan umum

Kenapa harus menggunakan Game Pass?+

Website ini menggunakan alur Game Pass. Setelah pembeli membuat Game Pass dan mengirim link-nya, admin dapat memeriksa link tersebut sebelum memproses order.

Apakah saya perlu memberikan password Roblox?+

Tidak. Jangan pernah memberikan password, OTP, cookie, atau kode keamanan akun. Cukup kirim data order dan link Game Pass sesuai instruksi.

Ke mana saya membayar?+

Metode pembayaran yang tampil di website adalah pilihan. Nomor/rekening pembayaran sebaiknya dikirimkan oleh admin melalui WhatsApp setelah order.
